Official Linux Distribution Repository

⚡ One-Line Automatic Install (Debian, Ubuntu, Fedora, Arch)

Detects your distribution and installs the native package automatically:

curl -fsSL https://dokjolly0.github.io/Git-Flux/install.sh | sudo bash

🐧 Ubuntu, Debian & Linux Mint (APT)

Add the official APT repository to receive automatic updates with sudo apt update:

# 1. Install official repository GPG key sudo mkdir -p /etc/apt/keyrings curl -fsSL https://dokjolly0.github.io/Git-Flux/KEY.gpg | sudo gpg --dearmor --yes -o /etc/apt/keyrings/gitflux.gpg # 2. Add repository source echo "deb [signed-by=/etc/apt/keyrings/gitflux.gpg] https://dokjolly0.github.io/Git-Flux/ ./" | sudo tee /etc/apt/sources.list.d/gitflux.list # 3. Update & Install sudo apt update && sudo apt install -y git-flux
